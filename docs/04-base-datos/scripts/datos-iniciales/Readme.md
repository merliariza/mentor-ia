# Datos iniciales - Mentor-IA

La base de datos de Mentor-IA no requiere la ejecución de scripts adicionales de inserción de datos para iniciar su funcionamiento.

Los registros se generan durante el uso de la plataforma, mediante el registro de usuarios y las funcionalidades de seguimiento del aprendizaje, evaluaciones y generación de recursos de repaso.

La estructura de la base de datos se encuentra definida en el archivo `DDL/mentor-ia-schema.sql`.
