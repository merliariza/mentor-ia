# Accesibilidad y UX - Mentor-IA

## Accesibilidad

El diseño de Mentor-IA contempla criterios de accesibilidad orientados a facilitar la interacción de los usuarios con la plataforma, procurando que los contenidos, controles y elementos de navegación sean claros, legibles y fáciles de utilizar.

### Contraste

La interfaz utiliza una combinación de fondos claros y elementos de texto en tonos oscuros para facilitar la lectura y diferenciar visualmente los componentes.

Los colores de la identidad visual cumplen diferentes funciones dentro de la interfaz:

- **Morado:** se utiliza como color de identidad y para destacar elementos de interacción.
- **Azul oscuro:** permite establecer jerarquías visuales y mantener una buena diferenciación frente a los fondos claros.
- **Blanco y beige:** se utilizan como base visual para proporcionar espacios limpios y facilitar la lectura.
- **Gris:** permite representar información secundaria y elementos complementarios.
- **Rojo:** identifica mensajes y situaciones de error.
- **Verde:** permite representar estados positivos y de éxito.

Los textos y elementos interactivos deben mantener una diferencia visual suficiente respecto a sus fondos para facilitar su identificación y lectura.

### Tipografía

La tipografía debe favorecer la legibilidad y mantener una presentación visual uniforme en toda la plataforma.

Se establecen los siguientes criterios:

- Utilizar estilos de texto claros y fáciles de leer.
- Diferenciar títulos, subtítulos, etiquetas y contenido mediante tamaños y pesos tipográficos.
- Mantener una jerarquía visual que facilite la identificación de la información principal.
- Evitar bloques extensos de texto sin separación visual.
- Conservar una presentación consistente en formularios, tarjetas, paneles y mensajes.

### Tamaño de elementos

Los elementos de la interfaz deben contar con dimensiones que permitan identificarlos e interactuar con ellos cómodamente.

Se consideran los siguientes criterios:

- Botones con dimensiones suficientes para facilitar su selección.
- Campos de formulario con espacio adecuado para ingresar y visualizar información.
- Iconos con un tamaño que permita reconocer su función.
- Separación apropiada entre controles para evitar selecciones accidentales.
- Espaciado uniforme entre los elementos de las diferentes secciones.

### Navegación

La navegación de Mentor-IA busca facilitar el acceso a las diferentes funcionalidades de aprendizaje mediante una organización clara de las secciones.

Los criterios de navegación incluyen:

- Mantener una estructura visual consistente entre las diferentes pantallas.
- Utilizar nombres e iconos que permitan reconocer las funcionalidades.
- Facilitar el acceso a las secciones principales de la plataforma.
- Diferenciar visualmente la opción o sección activa.
- Mantener mecanismos de navegación comprensibles y predecibles.

### Formularios

Los formularios deben facilitar el ingreso de información mediante campos identificados y mensajes de validación comprensibles.

Se consideran los siguientes criterios:

- Cada campo debe contar con una etiqueta que identifique la información solicitada.
- Los campos obligatorios deben tener validaciones correspondientes.
- Los mensajes de error deben aparecer asociados al campo que presenta el inconveniente.
- Los campos de contraseña deben utilizar un tipo de entrada que proteja visualmente su contenido.
- Los botones deben comunicar claramente la acción que ejecutan.
- Los errores deben identificarse mediante texto y recursos visuales, sin depender exclusivamente del color.

## Experiencia de usuario

La experiencia de usuario de Mentor-IA se orienta a ofrecer una interacción sencilla y organizada, permitiendo que los usuarios accedan a las herramientas de aprendizaje y consulten su progreso de manera comprensible.

### Consistencia

La interfaz mantiene una identidad visual común en las diferentes secciones de la plataforma, utilizando una paleta de colores, estilos de componentes y criterios de distribución coherentes.

Esta consistencia se aplica a:

- Botones y elementos interactivos.
- Tarjetas de información.
- Campos de formularios.
- Iconografía.
- Encabezados y títulos.
- Paneles y elementos de navegación.
- Mensajes de información, error y estado.

La reutilización de componentes visuales contribuye a mantener una experiencia uniforme y facilita la comprensión de las acciones disponibles.

### Feedback

La plataforma proporciona información visual para comunicar el resultado de las acciones realizadas por el usuario y el estado de las operaciones.

El feedback se presenta mediante diferentes recursos:

- Mensajes de validación en los formularios.
- Mensajes generales cuando una operación no puede completarse.
- Cambios en los textos de los botones durante el procesamiento.
- Actualización del contenido después de completar una operación.
- Respuestas del mentor de inteligencia artificial durante las interacciones del chat.

Estos elementos permiten que el usuario comprenda cómo responde la plataforma ante sus acciones.

### Estados

Los componentes de la interfaz contemplan diferentes estados para comunicar su comportamiento durante la interacción.

Entre ellos se encuentran:

- **Estado normal:** el componente se encuentra disponible para la interacción.
- **Estado de carga:** indica que una operación está siendo procesada.
- **Estado de error:** comunica que una operación no pudo completarse o que la información ingresada no cumple las validaciones.
- **Estado de éxito:** representa la finalización satisfactoria de una operación.

La identificación visual de estos estados permite ofrecer información oportuna y reducir la incertidumbre durante el uso de la plataforma.

### Responsive design

El diseño de Mentor-IA considera la adaptación de la interfaz a diferentes tamaños de pantalla, procurando conservar la legibilidad del contenido y la facilidad de interacción.

Los criterios de diseño adaptable incluyen:

- Ajustar la distribución de los componentes según el espacio disponible.
- Mantener la legibilidad de los textos en diferentes resoluciones.
- Evitar el desbordamiento horizontal del contenido.
- Adaptar tarjetas, formularios y paneles a pantallas de menor tamaño.
- Mantener los controles accesibles y fáciles de utilizar en dispositivos móviles.
- Conservar la jerarquía visual y la organización de la información independientemente del dispositivo.

La adaptación responsive busca proporcionar una experiencia de uso coherente tanto en equipos de escritorio como en tabletas y dispositivos móviles.
